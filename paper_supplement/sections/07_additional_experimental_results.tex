\section{Additional Experimental Results}
\label{supp:additional-results}

The repository contains machine-readable candidate tables for correctness,
LoRA adaptation, leakage proxies, baselines, stability, and local-emulation
runtime under \url{paper_results/}. These tables are staged evidence rather than
automatically accepted paper results. The claim ledger determines which rows
may enter the main paper, and the Code and Data Supplement manifest records the
source artifact, command status, execution environment, and measured versus
projected label for each selected result.

No result should be interpreted as a real TEE/GPU wall-clock measurement unless
its artifact records the hardware execution boundary. CPU emulation, synthetic
tensor probes, cost-model projections, and real-system measurements remain
separate evidence lineages.
