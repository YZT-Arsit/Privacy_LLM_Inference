The separate Code and Data Supplement manifest is the submission-time index of
commands and artifacts. Current repository evidence records seeds
$\{7,1234,2025\}$, but several hardware profiles are single runs and the H800
latency artifact does not record repetitions. The TDX evidence uses Quote v5;
its policy permits any measurement register value, which is a limitation rather
than a pinned-enclave claim. Absolute paths embedded in legacy JSON outputs must
be replaced by archive-relative paths before packaging.
