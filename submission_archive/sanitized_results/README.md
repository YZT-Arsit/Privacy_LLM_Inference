# Sanitized Results Gate

No raw artifact is copied here automatically. A result may be staged only after:

1. absolute paths, usernames, hostnames, account/instance identifiers, cache
   paths, credentials, and raw TDX host metadata are removed;
2. the compact artifact retains its schema, configuration, units, seeds, and
   measured/projected/proxy label;
3. its SHA-256 is recorded after sanitization; and
4. its data/model/code redistribution status is verified.
