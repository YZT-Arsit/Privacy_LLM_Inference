## 24 decoder layers note

The 'decoder layers' row is a FAMILY, not 24 separate rows. The layer loop is `apply_folded_prefill`/`apply_folded_decode` (folded_worker.py:298/:335) for inference and the HF `model(...)` stack (gate3_worker.py:218) for training. 24 layers = Qwen2.5-0.5B (the gate3 real-training model); the folded inference package is built for Qwen2.5-7B (28 layers, num_exec_layers configurable). Every layer applies the SAME compatible-mask schedule (per-layer signed-perm residual N, pairwise_rotation attention, shared SwiGLU permutation); the masked hidden is threaded layer->layer entirely in the N basis, so no layer materializes a plaintext residual in the folded path. In the gate3 TRAINING path all 24 layers run in PLAINTEXT on the untrusted GPU.
