\section{Complete Proofs}
\label{app:proofs}

All proofs use exact real arithmetic and the row-vector convention.  They prove
functional equivalence, not confidentiality.  The TEE owns the untransformed
quantities and masks; the GPU sees only the operands described in
Appendix~\ref{app:protocol}.

\begin{proof}[Proof of Theorem~\ref{thm:linear-execution}]
The dimensions are those in Appendix~\ref{app:operators}.  Substituting the
three transformed operands gives
\begin{align}
\Yt
&=(\X-\Tpad)\Nin\Nin^{-1}\W\Nout
  +\bias\Nout+\Tpad\W\Nout\nonumber\\
&=(\X\W+\bias)\Nout.
\end{align}
Right multiplication by $\Nout^{-1}$ therefore returns $\X\W+\bias$.
Invertibility of both masks and addition of the pad compensation are necessary
for this recovery rule; a pad entering a nonlinear operator is outside the
statement.  The masked bias $\bias\Nout$, rather than $\bias$, is the GPU
operand.
\end{proof}

\begin{proof}[Proof of Theorem~\ref{thm:attention-cache}]
Write $\overline{\Qmat}=\RoPE(\Qmat)$ and
$\overline{\K}=\RoPE(\K)$.  Post-RoPE masking gives
\begin{equation}
(\overline{\Qmat}\NQ)(\overline{\K}\NK)^{\mathsf T}
=\overline{\Qmat}(\NQ\NK^{\mathsf T})\overline{\K}^{\mathsf T}
=\overline{\Qmat}\overline{\K}^{\mathsf T}.
\end{equation}
Scaling, causal masking, and row-wise softmax therefore receive the same
scores.  If the plaintext probability matrix is $\mathbf P$, value aggregation
is $\mathbf P(\Vmat\NV)=(\mathbf P\Vmat)\NV$; folding $\NV^{-1}$ into the following
output boundary recovers the plaintext result.  In GQA, the calculation holds
for every query head precisely when its $\NQ$ is tied to the mask of the KV
head it addresses; MQA is the one-KV-head case.

For session-fixed masks, token-axis concatenation satisfies
\begin{equation}
[\K_1\NK;\ldots;\K_t\NK]=[\K_1;\ldots;\K_t]\NK,
\end{equation}
and identically for $\NV$.  Hence incremental masked-cache attention uses the
same plaintext scores and values as remasking the full prefix.  The proof fails
if masks mix heads, the compatibility equation is violated, group members use
inconsistent key masks, or cached rows use different within-session masks.
Pre-RoPE masking would additionally require a mask commuting with every RoPE
block; the canonical path avoids that restriction by masking after RoPE.
\end{proof}

\begin{proof}[Proof of Theorem~\ref{thm:lora-equivalence}]
Put $s=\alpha/\rtrue$.  Since
\begin{equation}
\At\Bt=\Nin^{-1}\Apad\Umix\Umix^{-1}\Bpad\Nout
=\Nin^{-1}\Amat\Bmat\Nout,
\end{equation}
the GPU adapter branch equals
$s(\X-\Tpad)\Amat\Bmat\Nout$.  Adding its pad compensation yields
$s\X\Amat\Bmat\Nout$; Theorem~\ref{thm:linear-execution} handles the base
branch.  Recovery thus gives the plaintext base-plus-adapter output.

Let $\Gmat$ be the plaintext output gradient and
$\Gt=\Gmat\Nout^{-\mathsf T}$.  Direct substitution into the GPU gradients
gives
\begin{align}
d\At&=\Nin^{\mathsf T}
 [s(\X-\Tpad)^{\mathsf T}\Gmat\Bpad^{\mathsf T}]
 \Umix^{-\mathsf T},\nonumber\\
d\Bt&=\Umix^{\mathsf T}
 [s\Apad^{\mathsf T}(\X-\Tpad)^{\mathsf T}\Gmat]
 \Nout^{-\mathsf T}.
\end{align}
Multiplying as in Eq.~\eqref{eq:app-lora-gradient-recovery} cancels the outer
masks.  Equation~\eqref{eq:app-lora-gradient-pad} restores the omitted
$\Tpad$ terms, producing
$d\Apad=s\X^{\mathsf T}\Gmat\Bpad^{\mathsf T}$ and
$d\Bpad=s\Apad^{\mathsf T}\X^{\mathsf T}\Gmat$.  The real-rank slices are
therefore the plaintext $d\Amat,d\Bmat$.  Likewise the GPU input gradient is
$s\Gmat\Bpad^{\mathsf T}\Apad^{\mathsf T}\Nin^{-\mathsf T}$, so the TEE's
chain rule multiplication by $\Nin^{\mathsf T}$ recovers the plaintext input
gradient.  Any deterministic trusted optimizer started from the same factors
and state consequently makes the same update.

The result requires exact rank-padding cancellation, the stated inverse
relations, trusted pad-gradient compensation, and the same optimizer rule and
state.  It covers delegated linear backward boundaries; it does not assert a
masked nonlinear backward implementation.
\end{proof}
