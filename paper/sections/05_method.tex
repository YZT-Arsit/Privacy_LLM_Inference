\section{Method}
\label{sec:method}

\subsection{System Overview}
\label{subsec:method-overview}

The TEE $\ctrl$ alternates trusted boundary work with transformed computation
on the GPU $\acc$. It owns $\params$, User-owned LoRA and optimizer state,
masks, pads, plaintext residuals, logits, and decoding. The GPU receives
transformed model/adapter operands and activations, performs delegated linear
algebra, attention, and compatible activations, and stores the masked KV cache.
Inference consists of prompt prefill followed by one-row decode calls;
adaptation adds transformed LoRA branches and delegated linear backward calls.

\begin{methodalgorithm}{End-to-end execution}
\label{alg:method-lifecycle}
\textbf{Input/output:} Provider model; User training data or prompt; updated
adapter or generated result returned to the User.\par
\begin{enumerate}
\setlength{\itemsep}{0pt}\setlength{\parskip}{0pt}\setlength{\parsep}{0pt}
\item $\ctrl$ validates the model, operator plan, and private mask schedule.
\item For each boundary, $\ctrl$ sends transformed operands; $\acc$ computes
and returns a transformed result; $\ctrl$ recovers when required.
\item Prefill initializes the masked per-layer KV cache. Each decode call
appends one masked row and returns masked logits for trusted decoding.
\item During adaptation, $\acc$ evaluates transformed LoRA forward/backward
branches; $\ctrl$ recovers gradients and updates the User-owned factors.
\item $\ctrl$ erases pass/session state and returns only the requested result.
\end{enumerate}
\end{methodalgorithm}

\subsection{Obfuscated Inference}
\label{subsec:linear-execution}

For a row-vector linear $\Y=\X\W+\bias$, the TEE samples invertible right
masks $\Nin,\Nout$ and an additive boundary pad $\Tpad$, then constructs
\begin{align}
\Xt&=(\X-\Tpad)\Nin,\nonumber\\
\Wt&=\Nin^{-1}\W\Nout,\nonumber\\
\Yt&=\Xt\Wt+\bias\Nout+\Tpad\W\Nout,\nonumber\\
   &=(\X\W+\bias)\Nout,\nonumber\\
\Recover(\Yt)&=\Yt\Nout^{-1}.
\label{eq:method-linear}
\end{align}
The GPU receives only the transformed input, weight, bias, and compensation in
the middle expression. A result is recovered before a TEE operator or retained
in its right-masked basis when the next GPU operator accepts that basis. The
canonical path evaluates embedding lookup, normalization with private gains,
RoPE, residual updates, logit recovery, and decoding in the TEE. Attention
softmax/value aggregation and permutation-compatible pointwise activations run
on the GPU; a shared permutation is used for both SwiGLU branches. Pads are
compensated before any nonlinear core. Full dimensions and operator boundaries
are in Appendix~\ref{app:operators}.

\subsection{Autoregressive Attention and KV Cache}
\label{subsec:attention-execution}

The TEE applies RoPE to recovered queries and keys, then masks each head as
$\Qt=\Qmat\NQ$, $\Kt=\K\NK$, and $\Vt=\Vmat\NV$. Query/key masks obey
\begin{equation}
\NQ\NK^{\mathsf T}=\mathbf I_{d_h},
\label{eq:method-attention}
\end{equation}
and the output projection folds the value-mask inverse. For GQA, every query
head in a group derives $\NQ$ from its shared key head's $\NK$; MQA is the
single-KV-head case. Prefill stores $\Kt,\Vt$ on the GPU. The key/value masks
remain fixed within a generation session, so decode appends one transformed row
without remasking the prefix; other boundary masks and pads remain call-local.

\subsection{Private LoRA Adaptation}
\label{subsec:lora-adaptation}

The TEE rank-pads the User-owned factors to $\Apad,\Bpad$ with
$\Apad\Bpad=\Amat\Bmat$ and samples a call-local invertible rank mixer
$\Umix$. It sends only
\begin{align}
\At&=\Nin^{-1}\Apad\Umix,&
\Bt&=\Umix^{-1}\Bpad\Nout.
\label{eq:method-lora-factors}
\end{align}
The GPU keeps base and adapter branches separate and evaluates
\begin{multline}
\Yt=\Xt\Wt+\frac{\alpha}{\rtrue}(\Xt\At)\Bt+\bias\Nout+\Tpad\W\Nout\\
+\frac{\alpha}{\rtrue}\Tpad\Apad\Bpad\Nout.
\label{eq:method-lora-forward}
\end{multline}
For backward execution, the TEE transforms the upstream gradient, the GPU
returns transformed factor gradients, and the TEE recovers their real-rank
slices and applies pad-gradient compensation. Loss evaluation, trusted
nonlinear derivatives, optimizer state, and every parameter update stay in the
TEE; refreshed transformed factors are created for the next call. Appendix
\ref{app:operators} specifies the complete backward and optimizer interface.
